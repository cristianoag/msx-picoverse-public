원설계 The Retro Hacker / rev 1.3~1.4 개정 ESLAB

## 0. rev 1.3 → 1.4 변경 요약

| 부품 | 처리 | 이유 |
|---|---|---|
| **D2** (B5819WS) | **삭제** | USB VBUS 역류 차단 다이오드. 이것 때문에 MSX 구동 중 J5의 VBUS가 0 V가 되어 USB 메모리가 인식되지 않았다 |
| **SW1** (SK-12D02) | **삭제** | ESP 전원 선택 스위치 |
| **Q3** (DTC114EUA) | **삭제** | VBUS 검출. D2 제거로 VBUS가 상시 활성이 되어 검출 자체가 무의미 |
| **Q4** (SSM3J332R) | **삭제** | ESP 전원 스위치 P-FET |
| **R40** (10k) | **삭제** | Q4 게이트 풀업 |
| **C12** (0.1µF) | **삭제** | Q4 게이트 소프트스타트 |
| **F1** (FSMD075) | 역할 변경 | `+5V ↔ VBUS` 양방향 경로이자 **USB 호스트 전류 제한** 소자 |
| **U2** (UDA1334MOD) | **뒷면 → 앞면 (파일 정정)** | rev 1.3 파일이 뒷면으로 잡고 있었으나 실물은 앞면이었다. 설계 변경이 아니라 파일을 실제 조립 상태에 맞춘 것. 180° 회전 배치로 3.5 mm 잭이 기판 좌측 외곽선 밖으로 3.13 mm 돌출 |

결과

```
rev 1.3 :  J5.VBUS ──D2──► F1 ──► +5V        (USB → 보드 단방향. 호스트 급전 불가)
rev 1.4 :  J5.VBUS ────── F1 ────── +5V      (양방향. MSX 5V가 USB 메모리를 구동)

ESP 전원 :  rev 1.3  SW1/Q3/Q4 경유 ESP_POW  →  rev 1.4  +3V3 상시
```

부품 수 110 → **104개**. 실장 97 / DNP 4 / 기판일체 3.

### 외형 101.15 mm — 100 mm 이하로 줄이지 않아도 된다

2026-09-23 JLCPCB 견적 화면에서 현재 거버 그대로 확인했다.

```
치수        101.15 × 66.05 mm   (거버 자동인식 "4개의 계층이 감지됨")
레이어      4 / 1.6 mm

배송        $9.74 (UPS Worldwide Express, 0.24 kg)
```

| 옵션 | 산출가격 |
|---|---|
| 기본 (HASL, 기본 스택업) | $8.00 |
| **+ ENIG** (표면 마감 +$17.40) | **$25.40** |
| **+ 임피던스 스택업 JLC04161H-3313** | **추가 비용 없음** |

**임피던스 스택업은 공짜다.** 고르지 않을 이유가 없다.
골드핑거는 주문 페이지 아래쪽의 별도 항목이고 값이 또 따로 붙으니,
켠 뒤의 합계를 다시 확인한다.

**한 변만 100 mm 를 넘는 것은 문제가 되지 않는다.** 4층 특가 구간이 그대로 적용되어
5장 $8.00 이 나온다. 엔지니어링 피가 붙는 쪽은 **양변이 모두 100 mm 를 넘을 때**로
보인다 (JLCPCB 문서에 명시되어 있지 않고, 견적 화면에서 치수를 바꿔 본 관찰 결과다).

이 보드는 66.05 mm 쪽이 여유가 크므로 **외형을 줄일 이유가 없다.**
셸 내부 프로파일에 맞춘 치수이므로 줄이면 오히려 케이스에 안 맞는다.

실제 주문에서 켜야 하는 항목은 **ENIG / 골드핑거(30° 또는 45° 베벨) / 임피던스 스택업**
세 가지다. 이 중 값이 올라가는 것은 ENIG 와 골드핑거뿐이고, 스택업은 무료다.

### 스택업을 JLC04161H-3313 으로 하는 이유

USB-C 의 D+/D- 는 F.Cu(L1) 전용 90 Ω 차동쌍이고, 기준면은 In1.Cu(L2) GND 다.
선폭 0.29 / 간격 0.203 mm 는 **L1-L2 유전체 두께 0.0994 mm** 를 전제로 계산한 값이다.

JLCPCB 주문 화면의 **레이어 스택업** 항목에서 `JLC04161H-3313` 을 고르면

```
Top       0.035
Prepreg   3313 x1   0.0994      <- USB 차동쌍의 기준 유전체
L2        0.0152
Core      1.265
L3        0.0152
Prepreg   3313 x1   0.0994
Bottom    0.035
```

기본 4층 스택업은 L1-L2 프리프레그가 이보다 두꺼워서, 같은 선폭·간격으로는
차동 임피던스가 90 Ω 에서 벗어난다.

**Impedance Control 은 `No requirement` 로 둔다.**
`Specify Stackup = Yes` 로 스택업을 지정하면 유전체 두께가 고정되고, 이 설계가
전제로 하는 것은 그것뿐이다. 별도 항목인 **Impedance Control ±10%** 는 JLCPCB 가
실제로 측정해서 보증해 주는 유료 서비스이고, **이것을 켜면 조립 옵션이 제한된다.**
끄고 스택업만 지정하면 `-3313` 과 **Economic PCBA 가 동시에 가능하다**
(2026-09-24 실제 견적에서 확인 — 5개 기준 Economic 총액 $135.54).

USB 2.0 Full Speed 이고 배선이 짧아 임피던스 보증까지는 필요 없다.

**Via Tented 는 선택할 수 없다.** JLCPCB 가 **Via Plugged 로 무상 업그레이드**한다는
안내가 뜬다. Plugged 가 충전 품질도 더 낫다. `Filled & Capped` 계열을 고르면
Horizontal Electroless Copper Plating 이 강제되어 둘이 합쳐 약 $21 이 붙는다.

### 표면처리를 ENIG로 하는 이유

J11은 MSX 카트리지 슬롯에 직접 꽂히는 골드핑거다. HASL은 표면이 고르지 않아
삽입 시 슬롯 접점을 긁고, 반복 삽발 내구성이 떨어진다. 취미 프로젝트라도
슬롯에 꽂는 기판은 ENIG로 하는 편이 안전하다. JLCPCB에서는 골드핑거 옵션을
선택하면 해당 면이 별도 도금된다.

## 3. SMT 실장 발주

### 3.1 좌표계

이 프로젝트는 **보조 원점(aux origin)을 쓰지 않는다.** 거버가 절대좌표로 출력되며
CPL도 동일 원점을 쓴다.

```
Mid X =   KiCad X + 중심보정 dx
Mid Y = −(KiCad Y + 중심보정 dy)   ← KiCad는 Y 아래가 +, 거버/CPL은 Y 위가 +
Layer =  top / bottom
```

**중심 보정(centroid)** — JLCPCB는 CPL 좌표를 *부품 중심*으로 읽는다.
KiCad 풋프린트 원점은 커넥터류에서 핀1이나 기구 기준점에 있는 경우가 많아
그대로 내보내면 부품이 엉뚱한 곳에 앉는다. `tools/rev14_jlcpcb.py` 가
**패드(기구홀 제외) 바운딩박스 중심**을 계산해 보정한다.

| 부품 | dx | dy | 설명 |
|---|---:|---:|---|
| J4 microSD | 0.00 | **−5.30** | 원점이 카드 삽입구 쪽에 있음 |
| J5 USB-C | 0.00 | **−1.46** | 원점이 실드 기준 |
| S1 | 0.00 | +0.30 | |
| 나머지 93개 | 0.00 | 0.00 | 원점 = 패드 중심 |

> 2026-09-24 : 처음에는 **코트야드** 중심으로 보정했는데 풋프린트마다 코트야드
> 정의가 달라 오히려 더 틀어졌다(J4가 기판 밖으로 7 mm 이상). 패드 바운딩박스
> 중심이 JLCPCB 기준과 가장 잘 맞는다.

CPL 헤더는 JLCPCB 표준 그대로다: `Designator, Mid X, Mid Y, Layer, Rotation`

### 3.2 반드시 확인할 것

**① LCSC 부품번호**
`tools/rev14_jlcpcb.py` 의 `LCSC` 표에 2026-09 기준으로 확인한 번호가 들어 있고
BOM 에 자동으로 기입된다. 35품목 중 32품목이 채워져 있다. 나머지 3개는 §3.4 참조.

**② 회전값을 미리보기에서 확인할 것**
JLCPCB 부품 라이브러리의 기준 각도가 KiCad와 다른 패키지가 많다.
2026-09-24 미리보기에서 실측해 확정한 보정값 (`ROT_FIX`) :

| 풋프린트 | 보정 | 확인 기준 |
|---|---:|---|
| SOT23 (Q2) | +90° | 바디 긴축이 패드 배열과 같은 방향 |
| SOT23-6L (Q1) | +270° | 핀1 마커가 실제 패드 1 위 |
| SOD323 (D1) | +180° | 캐소드 밴드 방향 |
| DO214SMB (TVS1) | +180° | |

이 단계를 건너뛰면 트랜지스터·다이오드가 뒤집혀 실장된다.

**③ 뒷면 부품 없음**
rev 1.4 에서 U2 가 앞면으로 정정되어 **이 보드에는 뒷면 부품이 하나도 없다.**
CPL 의 `Layer` 열은 전부 `top` 이다.

**④ 미리보기는 참고용이다**
JLCPCB 뷰어는 자기네 3D 모델을 CPL 좌표에 얹어 그린다. 모델 원점이 부품마다
달라서 커넥터가 기판 밖으로 조금 나와 보일 수 있다. 화면에도
*"The preview for reference only. Check final part placement at DFM Analysis"*
라고 적혀 있다. 최종 확인은 주문 후 4~6시간 뒤 **Order History → DFM Analysis** 에서 한다.

### 3.4 주문 화면에서 "Do not place" 로 빠지는 부품

업로드는 되지만 JLCPCB 가 실장하지 않는다. 주문 화면에서 **Do not place** 를
선택하고 넘어간 뒤, 받아서 직접 납땜한다.

| 부품 | 값 | 사유 | 대응 |
|---|---|---|---|
| **S1** | A06-B6-1 측면 푸시 스위치 | **JLCPCB / LCSC 라이브러리에 없다.** 검색해도 나오지 않는다 | 데브마트에서 직접 구매 — `datasheet/A06-B6-1.pdf`, <https://www.devicemart.co.kr/goods/view?no=1322059> |
| **IC1** | AP63200WU-7 (C2071868) | **재고 부족.** 2026-09 기준 JLCPCB 재고가 이 보드 수량을 못 채운다 | LCSC 에서 따로 구매하거나, 재고가 찰 때까지 기다린다. TSOT-26 이라 손납땜 가능 |
| U1 | Core2350B 모듈 | 스루홀 모듈 | 직접 구매·납땜 |
| U2 | UDA1334A 모듈 | 스루홀 모듈, 6 mm 스탠드오프 필요 | 직접 구매·납땜 |

> 결과적으로 JLCPCB SMT 로 실장되는 것은 **32품목**이다.
> BOM 화면에서 `Select` 를 전체 체크하고 **Next** 를 누르면 위 4개에 대해
> 팝업이 뜨는데 **Do not place** 를 고르면 된다.

> **⚠ J5 가 미리보기에서 사라지면** — BOM/CPL 을 다시 올리면 J5 가 수량 0 에
> 체크 해제 상태로 돌아오는 경우가 있다. 선택되지 않은 부품은 배치 미리보기에
> **아예 그려지지 않으므로** "USB 커넥터가 없어졌다" 로 보인다.
> *Bill of Materials* 탭에서 J5 의 `Select` 를 다시 체크하면 복구된다.
> JLCPCB 가 `The processing of this component is difficult` 경고와 함께
> 보드당 $0.03 의 special component fee 를 붙이는데, SMD + 스루홀 혼합
> 커넥터에서는 정상이다.

J4(microSD)는 SMD 13핀 + NPTH 2개 구성이라 **SMT 실장 가능**하다.
J5(USB-C)는 SMD 16 + 스루홀 4 혼합인데 2026-09-24 미리보기에서 실장 대상으로 잡혔다.

## 4. 수동 조립 주의사항

SMT를 맡기든 전부 직접 하든, 아래는 사람이 조립하는 부분이다.

### 4.1 모듈 (U1 / U2 / J2)

- **핀헤더 소켓(암) 사용 금지.** 소켓 높이 때문에 케이스를 닫을 수 없다.
- **U1 / J2** 는 핀헤더의 플라스틱 지지대(스페이서)를 제거한 뒤 조립한다.
  모듈이 기판에 밀착되어야 한다.
- **U2 는 반대다 — 밀착시키면 안 된다.** 부품면을 아래로 엎어 꽂으므로
  6.00 mm 스탠드오프가 필요하다. 아래 4.2 참조.

### 4.2 U2 (UDA1334A I2S DAC 모듈) — rev 1.4 에서 앞면으로 정정

- **rev 1.3 파일이 뒷면(B면)으로 잡고 있었으나 실물은 앞면(F면)이었다.**
  설계 변경이 아니라 파일을 실제 조립 상태에 맞춘 것이다.
  이제 이 보드에 뒷면 부품은 하나도 없다.
- **모듈은 부품면을 아래로 엎어서 꽂는다.** UDA1334ATS · 47µF 2개 · 3.5 mm 잭이
  2350 기판을 향하고, 핀헤더는 모듈의 **부품면**에서 나와 기판을 관통한다.
  위에서 보이는 것은 모듈의 민면이다.
- **스탠드오프 6.00 mm 가 필요하다.** 47µF 캔 5.40 mm 가 들어갈 공간이 있어야 한다.
  핀헤더 플라스틱 지지대 2.54 mm 로는 부족하므로 **긴핀 헤더(핀 길이 11 mm 이상)
  또는 별도 스페이서**를 쓴다.
- 핀 관통 길이 = 기판 아래 3.2 + 스탠드오프 6.0 + 모듈 1.6 ≈ **최소 10.8 mm**
- **3.5 mm 오디오 잭이 기판 좌측 외곽선 밖으로 3.13 mm 돌출한다.**
  잭 중심 높이는 기판면에서 약 3.5 mm. 케이스 잭 타공을 여기에 맞춘다.
- F.Silkscreen 의 1번 핀 표시를 확인할 것.

```
기판면 기준 Z (mm)
  -3.20 ─ 핀헤더 하단 (기판 관통)
   0.00 ─ 2350 기판 표면
   0.60 ─ 47µF 캔 바닥          ← 스탠드오프를 결정
   1.00 ─ 3.5mm 잭 바닥
   6.00 ─ 모듈 PCB 아랫면(부품면)
   7.60 ─ 모듈 PCB 윗면(민면)   ← 전고
  10.35 ─ 상판 셸 안쪽          ← 여유 2.75
```

> **높이 여유는 충분하다.** 기판 위로 10.35 mm 가 있고 전고는 7.60 mm 다.
> (rev 1.3 문서에 적혀 있던 "하판 셸 5.5 mm 간섭"은 U2 를 뒷면으로 잡은 파일상의
> 착오에서 나온 값이며, 실재했던 문제가 아니다.)
> 남은 과제는 잭 돌출부의 케이스 타공과 6 mm 스탠드오프 부품 확보다.

### 4.3 J5 (USB-C) — rev 1.4 에서 역할이 늘었다

- 펌웨어 업로드 포트이자 **USB 메모리(매스스토리지) 호스트 포트**를 겸한다.
- VBUS는 F1을 통해 `+5V`에서 **상시 공급**된다. 별도 전원 스위치가 없다.
- **★★ MSX에 카트리지를 꽂은 상태로 PC에 USB 케이블을 연결하지 말 것.**
  D2가 없으므로 MSX 5 V가 PC의 VBUS로 역류한다. 펌웨어 업로드는 카트리지를
  MSX에서 뺀 상태에서 한다. 자세한 근거는 `doc/USB_MSC_2350.md` §7.3.
- CC1/CC2는 Rd 5.1k 고정이라 USB-C 규격상 싱크(UFP) 배선이다. USB2 데이터에는
  영향이 없지만, "USB-C 규격 준수 호스트"로 표기하지는 말 것.

### 4.4 S1 (A06-B6-1 측면 푸시 스위치)

- 기판 상단 돌출부에 실장되며 액추에이터가 기판 외곽선보다 0.5 mm 바깥으로 나온다.
  케이스 버튼 타공·플런저 위치를 확인할 것.
- **위치결정 보스 Ø0.6 두 개가 기판의 Ø0.75 비도금 홀에 완전히 안착된 것을
  확인한 뒤 납땜한다.** 떠 있으면 측면 하중에 단자가 뜯어진다.
- 금속 커버 고정탭(패드 3·4)은 GND에 연결되어 있고 각 탭 중앙에 앵커 비아가 있다.
  수땜 시 배럴에 납이 차면서 리벳처럼 고정된다. 뒷면은 마스크로 덮여 있어
  납이 새어나오지 않는다.

### 4.5 J2 (ESP-01) — rev 1.4

- ESP-01 전원이 **+3V3 상시**로 바뀌었다. 전원 선택 스위치가 없으므로
  보드에 전원이 들어오면 ESP도 항상 켜진다.
- 스트래핑 풀업 R8 / R9 / R10 / R39 는 모두 **4.7k** 로 통일되었다.

### 4.6 J3 (SWD 헤더)

- 기본 **DNP**. 펌웨어 디버깅이 필요할 때만 실장한다.
- 실장할 경우 **라이트 앵글(수평) 헤더만** 사용한다. 수직형은 케이스에 간섭한다.
