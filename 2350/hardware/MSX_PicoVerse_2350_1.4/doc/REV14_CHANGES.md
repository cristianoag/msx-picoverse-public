# MSX PicoVerse 2350 — rev 1.3 → rev 1.4 변경 요약

**작성** 2026-09-19 / ESLAB
**보드** `MSX_PicoVerse_2350_1.4`

이 문서는 1.4 폴더를 열었을 때 제일 먼저 읽는 목차다. 상세는 각 문서로 간다.

---

## 1. 무엇을 왜 바꿨나

**USB 메모리(매스스토리지)가 인식되지 않던 원인을 하드웨어로 제거했다.**

rev 1.3 은 J5(USB-C) 의 VBUS 에 전원을 공급하는 경로가 없었다. D2(B5819WS)가
`VBUS → 보드` 단방향만 허용했으므로 MSX 구동 중 J5 의 VBUS 는 0 V 였고,
버스 전원으로 동작하는 USB 메모리는 enumeration 이전에 켜지지도 않았다.
(2040 보드가 되는 이유는 외부 포트가 모듈 자신의 USB-C 이고 그 VBUS 가
모듈 5V 핀과 직결이기 때문이다. → `doc/USB_MSC_2350.md` §3.4)

D2 를 제거하자 VBUS 검출(Q3)과 그에 딸린 ESP 전원 선택 회로(Q4/SW1/R40/C12)가
의미를 잃어 함께 정리했다.

## 2. 삭제된 부품 6개

| 부품 | 값 | 역할 | 삭제 사유 |
|---|---|---|---|
| **D2** | B5819WS | USB VBUS 역류 차단 | 이것 때문에 USB 호스트 급전 불가 |
| **SW1** | SK-12D02 | ESP 전원 선택 | ESP 를 +3V3 상시로 단순화 |
| **Q3** | DTC114EUA | VBUS 검출 | VBUS 가 상시 활성이 되어 검출 무의미 |
| **Q4** | SSM3J332R | ESP 전원 스위치 P-FET | SW1 과 함께 삭제 |
| **R40** | 10k | Q4 게이트 풀업 | 〃 |
| **C12** | 0.1µF | Q4 게이트 소프트스타트 | 〃 |

부품 수 **110 → 104개** (실장 97 / DNP 4 / 기판일체 3)

## 2-1. 정정된 배치 — U2

| 부품 | 변경 | 내용 |
|---|---|---|
| **U2** UDA1334MOD | **B.Cu → F.Cu (파일 정정)** | rev 1.3 파일이 U2 를 뒷면으로 잡고 있었고 3D 모델도 부품면이 반대였다. **둘 다 실물과 달랐다.** rev 1.4 에서 파일을 실제 조립 상태에 맞췄다 — 앞면, 180° 회전, 3.5 mm 잭이 좌측 외곽선 밖으로 3.13 mm 돌출. **이 보드에 뒷면 부품은 하나도 없다** |

**설계 변경이 아니라 파일 정정이다.** rev 1.3 실물은 처음부터 이 배치로 조립되어 검증되었다.
따라서 "하판 셸 5.5 mm 간섭"도 실재했던 문제가 아니라 파일상의 착오였다.
기판 위로 10.35 mm 가 있고 U2 전고는 7.60 mm 이므로 여유 2.75 mm.
남은 과제는 잭 돌출부의 케이스 타공과 6 mm 스탠드오프 부품 확보다.

## 3. 바뀐 전원 구조

```
[USB VBUS]
  rev 1.3   J5.VBUS ──D2──► F1 ──► +5V            단방향. USB 메모리 급전 불가
  rev 1.4   J5.VBUS ─────── F1 ─────── +5V        양방향. MSX 5V 가 USB 메모리를 구동

[ESP-01 전원]
  rev 1.3   +3V3 ─ SW1 / Q3 / Q4 ─ ESP_POW ─ J2.8
  rev 1.4   +3V3 ───────────────────────────── J2.8   상시
```

### F1 의 역할이 바뀌었다 ★★

`FSMD075-1812` 는 이제 `+5V ↔ VBUS` 를 잇는 **유일한 직렬 소자**이며,
홀드 0.75 A / 트립 1.5 A 가 곧 **USB 호스트 전류 제한**이다.
**0 Ω 점퍼로 대체하면 안 된다.**

### 반드시 지켜야 할 운용 규칙 ★★

**MSX 에 카트리지를 꽂은 상태로 PC 에 USB 케이블을 연결하지 말 것.**
D2 가 없으므로 MSX 5 V 가 PC 의 VBUS 로 역류한다.
펌웨어 업로드(BOOTSEL)는 카트리지를 MSX 에서 뺀 뒤 한다.

| 조합 | 결과 |
|---|---|
| MSX ON + PC 미연결 | 안전 (의도한 동작) |
| 카트리지 미장착 + PC 연결 | 안전 — Q2 바디다이오드가 PC→MSX 차단 |
| MSX 장착·전원 OFF + PC 연결 | 안전 — `+5V_MSX` = 0 V |
| **MSX ON + PC 연결** | **금지 — 역급전** |

### 잃은 것

- **ESP 를 끌 수단이 없다.** 보드에 전원이 들어오면 ESP-01 도 항상 켜진다.
  아이들 ~70 mA 가 부담되면 CH_PD(GP44) / RST(GP42) 로 하드 파워다운(~20 µA).
  → 이 때문에 1.3 에서 "GP44 연결 삭제 권장" 이라고 쓴 판단을 **철회**했다.
- **VBUS 계통 보호 소자가 없다.** TVS1 은 `+5V_MSX` 진입점에만 있다.

## 4. U2 3D 모델 정정

구 모델에는 결함이 두 개 있었다.

1. **부품면이 캐리어 보드를 향하도록** 그려져 있었다. 모듈 PCB 가 z 6.00~7.60 에 떠 있고
   IC·47µF·3.5mm 잭이 그 아래 z 0~6.00 에 매달려 있었다.
   실물은 반대다 — 핀헤더는 모듈의 **부품 없는 면**에서 나온다.
2. **좌표계의 Y 부호가 풋프린트와 반대**였다. 9핀 열과 6핀 열이 서로 바뀐 자리에
   그려져 있었는데, 모듈이 Y 방향으로 거의 대칭이라 눈에 띄지 않았다.
   이 상태에서 풋프린트를 180° 돌려 쓰면서 3D 오프셋/회전을 손으로 맞추다 보니
   **핀헤더가 위로 솟는** 결과가 나왔다.

새 생성기 `tools/make_uda_model.py` 는 **`.kicad_pcb` 의 U2 풋프린트에서 패드 좌표와
F.Fab 외형을 직접 읽어** 모델을 만든다. 상수를 박아두지 않으므로 다시 어긋날 수 없다.

**실장 방향은 부품면 아래(component side down)로 확정했다.**
모듈을 엎어 꽂아 부품면이 2350 기판을 향하고, 핀헤더는 모듈의 부품면에서 나온다.
47µF 캔 5.40 mm 가 기판과 모듈 사이에 들어가야 하므로 **6.00 mm 스탠드오프**가 필요하다.

```
기판면 기준 Z (mm)
  헤더 핀      -3.20 .. 7.90     ← 기판을 관통, 관통 길이 최소 10.8
  47µF 캔       0.60 .. 6.00     ← 스탠드오프를 결정
  3.5mm 잭      1.00 .. 6.00
  UDA1334ATS    4.90 .. 6.00
  모듈 PCB      6.00 .. 7.60     ← 민면이 위
  전고                   7.60
```

> 핀헤더 플라스틱 지지대는 2.54 mm 뿐이라 부족하다.
> **긴핀 헤더(핀 길이 11 mm 이상) 또는 별도 스페이서**가 필요하다.
> 생성기의 `GAP` 을 0 으로 두면 부품면이 위를 향하는 반대 실장(전고 7.00)이 된다.

XY 는 풋프린트에서 그대로 읽으므로 패드와 핀이 정확히 일치한다.
검증: 모듈 보드 X −16.43…21.67 / Y −12.15…13.25, 잭 X −19.56…−1.86 —
둘 다 풋프린트 F.Fab 과 소수점까지 동일하다.

### 3D 설정

| 대상 | offset (xyz) | rotate (xyz) | 이유 |
|---|---|---|---|
| `.kicad_pcb` 의 U2 | `0 0 0` | `0 0 0` | 모델이 이 인스턴스 프레임으로 생성됨 |
| `.pretty/UDA1334MOD.kicad_mod` | `2.4 -0.08 0` | `0 0 180` | 라이브러리 풋프린트는 180° 덜 돌아간 상태 |

> **라이브러리와 PCB 인스턴스의 패드 좌표가 다르다.** PCB 쪽 U2 는 라이브러리를
> 180° 회전 + (2.40, 0.08) 이동한 형태로 패드가 굳어 있다.
> KiCad 에서 **"라이브러리에서 풋프린트 업데이트"를 실행하면 이 회전이 풀린다.**
> 배치를 확정했으면 `.pretty` 쪽 풋프린트도 같은 방향으로 맞춰 두는 것이 안전하다.
