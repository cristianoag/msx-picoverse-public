## 4. ❌ 해결이 필요한 불일치

### 4-1. 셸 길이 65.2 vs 69.5

지시서 §3 은 "세로 KiCad y = 0 ~ −65.2, 전체 높이 65.2" 라고 하지만
**두 메시 모두 69.4~69.5** 다. 앞으로 1.14, 뒤로 3.16 더 나간다.

X가 0.016 mm로 맞는데 Y만 4.3 mm 틀릴 수는 없으므로 **좌표 변환 문제가 아니다.**
y 별 단면을 보면:

```
y = −1.0 … 65.2   바닥판만 (하판) / 천정판만 (상판)
y = 66.0          뒷벽 등장
y = 67.0 … 68.36  뒷쪽 립
```

즉 DXF에서 읽은 **65.2 는 셸 외곽이 아니라 내부 공동의 뒷면**으로 보인다.
지시서 §7 완료기준의 "외곽 108.984 × 65.2 (±0.05)" 는 **현물과 맞지 않는다.**

**→ 실물 재현이 목표이므로 메시값 69.5 를 채택할 것을 제안한다.** 확인 필요.

### 4-2. PCB 우측이 셸 내벽과 간섭

| 출처 | 셸 우측 내벽 X |
|---|---|
| 지시서 §3 (DXF) | +47.276 → PCB +47.150 대비 **0.126 여유** |
| 하판 메시 실측 | **+46.974** → PCB +47.150 대비 **0.176 간섭** |

지시서는 "의도적 타이트, 오류 아님" 이라 했지만 실측은 반대로 **0.176 겹친다.**
DXF 최내곽(104.452) 과 메시 내부폭(104.000) 이 0.452 다른 것과 같은 원인이다.

### 4-3. 상판 보스 XY 미확정

상판은 홀 중심에서 수직광선이 z 8.854…9.850 만 잡혀, 나사구멍이 천정판을 관통하지
않는 것처럼 나온다. 상판 보스 중심이 하판과 다른 위치일 가능성이 있어 **전용 탐침 필요**.

## 5. Z 원점 재정의 제안

지시서 §2 는 "model Z = 기판 상면 = 0" 으로 정의한다. 실측 기준:

```
PCB 하면 = 지지턱 상면 = −4.500 (메시 프레임)
PCB 상면 = −4.500 + 1.5982 = −2.902
→ 메시 Z 에 +2.902 를 더하면 PCB 상면이 0 이 된다
```

재정의 후 값:

| 항목 | 메시 Z | PCB상면 기준 Z |
|---|---|---|
| 하판 바깥 바닥 | −7.800 | **−4.898** |
| 하판 바닥 상면 | −6.000 | −3.098 |
| PCB 하면 | −4.500 | −1.598 |
| PCB 상면 | −2.902 | **0.000** |
| 하판 보스 상면 | −0.250 | +2.652 |
| 합체 립 구간 | 1.450…3.850 | +4.352…+6.752 |
| 상판 내부 천정 | 7.450 | **+10.352** |
| 상판 바깥 천정 | 9.850 | **+12.752** |

**PCB 상면에서 천정까지 10.352 mm** — U1 Core2350 모듈 6.80, J2 ESP-01 등 최고 부품과
여유가 있다. 하판 쪽은 PCB 하면에서 바닥 상면까지 1.500 mm.

> **2026-09-23 정정.** 여기 원래 "U2 가 하면에서 7.60 mm 내려오므로 6.1 mm 간섭한다"고
> 적혀 있었다. **U2 는 뒷면이 아니라 앞면 실장이다.** rev 1.3 실물이 그렇게 조립되어
> 검증되었고, 뒷면으로 잡혀 있던 것은 KiCad 파일 쪽 착오였다(rev 1.4 에서 정정).
> 따라서 하판 간섭은 없고, U2 는 상면 여유 10.352 mm 안에 전고 7.60 mm 로 들어간다 —
> 여유 2.75 mm.

전체 조립 두께 = −7.800…9.850 = **17.650 mm** (상·하판 립 2.400 겹침)

## 8. ❌ 상판·하판은 서로 맞는 짝이 아니다

세 가지를 독립 검증했다.

### 8-1. 나사 위치 — 일치 ✅

상판 천정을 0.25 mm 격자로 훑어 구멍 영역의 무게중심을 구했다.

| | 상판 실측 중심 | 하판 보스 중심 | 편차 |
|---|---|---|---|
| 좌 | (−28.415, 21.223) | (−28.15, 21.20) | **0.266** |
| 우 | (+27.681, 16.062) | (+27.85, 16.00) | **0.180** |

### 8-2. 외곽 — 거의 일치 ✅

| | 하판 | 상판 | 차이 |
|---|---|---|---|
| X 길이 | 109.000 | 109.000 | 0.000 |
| Y 길이 | 69.500 | 69.400 | 0.100 |
| X min/max | −59.526 / 49.474 | −59.500 / 49.500 | +0.026 |

### 8-3. 합체 립 — **맞지 않는다** ❌

하판 측벽을 Z로 0.25 mm씩 훑어 단차를 찾았다.

```
z ≤ +0.25   벽 두께 2.500   (x −59.526 … −57.026)
z ≥ +0.50   벽 두께 1.000   (x −58.026 … −57.026)   ← 텅(tongue)
→ 리베이트 단차 z ≈ +0.375, 리베이트 폭 1.500 (x −59.526 … −58.026)
```

상판 측벽은 **2.400 두께** (x −59.500 … −57.100), 하단 z = 1.450.

**2.400 두께 벽은 1.500 폭 리베이트에 들어갈 수 없다.**
텅 바깥면(−58.026)과 상판 벽 안쪽면(−57.100) 이 겹쳐 **0.926 mm 간섭**한다.

y = 12 / 25 / 33.6 / 45 / 58 여섯 위치, z = 1.45 ~ 3.85 전 구간에서
**모두 0.926 mm (국부적으로 1.0 ~ 1.43)** 로 일정하다. 메시 아티팩트가 아니다.

수직으로도 어긋난다 — 리베이트 바닥은 z = +0.375 인데 상판 벽 끝은 z = 1.450 으로
**1.075 mm 떠 있다.**

격자 간섭 검사에서도 재료가 양쪽에 다 있는 438개 탐침 중 **26개가 Z 구간까지 겹쳤고,
최대 겹침 2.400 mm** (뒷벽 부근) 였다.

### 8-4. 판정

두 메시는 **같은 MSX/코나미 카트리지 계열의 서로 다른 출처 셸**이다.
외곽·나사 패턴은 표준이라 일치하지만 립 결합부가 호환되지 않는다.
이름도 계보가 다르다 — `RevC_BOTTOM_MSXCART__KONAMIType` (범용 코나미형 하판)
vs `splider_flash_top` (특정 카트리지 상판).

X 방향 간섭이 좌우 대칭이므로 **평행이동으로는 해결되지 않는다.**

### 8-5. 선택지

| 안 | 내용 |
|---|---|
| A | 하판 립(리베이트 1.500 / 텅 1.000)을 기준으로 **상판을 새로 설계** |
| B | 상판 벽(2.400)을 기준으로 **하판 리베이트를 2.4+ 로 넓혀 재설계** |
| C | **립을 새로 설계** — 외곽·나사·벽두께만 메시에서 가져오고, 3D 프린팅용 편측 0.15~0.2 유격(§S6)을 처음부터 반영 |

§S6 이 어차피 합체 입술에 유격을 넣으라고 요구하므로 **C안이 자연스럽다.**

## 10. S2 — DXF 파싱 결과

FreeCAD `importDXF` 는 headless 에서 **0개**를 반환했다. 도면이 LINE/ARC/CIRCLE 뿐이라
**DXF 그룹코드를 직접 읽는 파서**(`tools/dxfread.py`)로 대체했다.

### 10-1. 엔티티 집계 — 지시서 §3 과 완전 일치

| 종류 | 개수 | 처리 |
|---|---|---|
| LINE | 328 (layer 0 : 305) | 사용 |
| ARC | 26 (layer 0 : 24) | 사용 |
| CIRCLE | 19 (layer 0 : 17) | 사용 |
| ELLIPSE | 17 | 퇴화 — 무시 |
| DIMENSION 15 · MTEXT 3 · LEADER 3 · HATCH 3 · TEXT 1 | 25 | 주석 — 제외 |
| layer `02___PRT_ALL_AXES` (LINE 23 · CIRCLE 2 · ARC 2) | 27 | 중심선 — 제외 |

### 10-2. 좌표계 재확인 ✅ — 자릿수까지 일치

Ø2.700 원 두 개가 **정확히 (−28.150, 21.200) 과 (+27.850, 16.000)**.
간격 dx 56.000 / dy 5.200 — 지시서 §2 기준값 그대로다. **변환식 확정.**

### 10-3. 평면도 2개 분리

| | 엔티티 | X 범위 | Y 범위 |
|---|---|---|---|
| VIEW-1 | 274 | −59.442 … 49.542 | −1.000 … 68.392 |
| VIEW-2 | 89 | 102 … 210.839 | −155.177 … −85.784 |

VIEW-2 = VIEW-1 을 **x = 75.6985 기준 좌우 반전 + Y −154.177 평행이동**.
(양쪽 Ø2.7 홀 좌표 합이 151.397 로 일정, Y 차이는 −154.177 로 일정)

### 10-4. 4중 윤곽 — 지시서 §3 표와 일치 ✅

| 윤곽 | 좌 | 우 | 폭 |
|---|---|---|---|
| 최외곽 | −59.442 | +49.542 | **108.984** |
| 2번째 | −58.950 | +49.050 | 108.000 |
| 3번째 | −58.050 | +48.150 | 106.200 |
| 최내곽 | −57.176 | +47.276 | 104.452 |

세로는 y −1.000 … +68.392 = **69.392** — 채택하신 값과 정확히 같다.

### 10-5. ❌ 폐곡선이 하나도 없다 — 다만 대부분은 실제 형상

끝점 근접 연결(허용 0.02)로 체이닝한 결과 **닫힌 루프 0개, 열린 체인 36개**.
최외곽 윤곽을 뜯어보면 이유가 분명하다.

**윗변 (y = 68.392)** — 두 토막뿐이다.
```
x −55.450 … −44.950   (10.500)
x  36.050 …  45.550   ( 9.500)
가운데 x −44.950 … +36.050 = 81.000 이 비어 있고,
양 끝에 y 68.392→67.892 로 내려가는 0.500 짜리 수직 토막이 있다
```
**81.000** 은 지시서 §3 의 "라벨 영역 81.0 (W)" 와 일치한다 — 즉 결손이 아니라
**뒷변이 0.5 만큼 단차진 실제 형상**이다.

**아랫변 (y ≈ −1.0)** — 여섯 토막이 y −0.945 / −0.996 / −1.000 세 높이에 흩어져 있다.
```
−59.442 … −56.147  (y −0.996)
−55.650 … −53.950  (y −1.000)
        ← 6.000 공백 (x −53.950 … −47.950)
```
